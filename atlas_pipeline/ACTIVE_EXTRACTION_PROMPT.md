## Core extraction rules
1. Output exactly one JSON object valid against the schema below; nothing else.
2. `quote` is copied verbatim from the given text; `char_start`/`char_end` index that exact text (end exclusive).
3. `value_raw` is the number as printed (sign, comparator, uncertainty kept); every numeric token in it must appear in `quote` as a whole token with the same sign.
4. `source_role`: `this_study` only for values this paper measured; values the paper attributes to earlier work are `cited_prior_work`; undecidable origin is `uncertain`.
5. `evidence_modality` names where the value is printed: `text`, `table`, `si_table`, `figure_vector`, `figure_raster`, `figure_caption`.
6. `stance` (optional per row, required per paper when the paper interprets dynamics): `supports`, `no_dynamics_in_window`, `unclear`, `artefact_suspected`.
7. Allowed unit dimensions per quantity (a spectrometer field such as 600 MHz is never the unit of a value):
  - `delta_omega`: chemical_shift, rate
  - `kab`: rate
  - `kba`: rate
  - `kclose`: rate
  - `kct`: rate
  - `kex`: rate
  - `kopen`: rate
  - `noe`: dimensionless
  - `pa`: dimensionless, fraction
  - `pb`: dimensionless, fraction
  - `pi`: dimensionless, fraction
  - `population`: dimensionless, fraction
  - `r1`: rate
  - `r1rho`: rate
  - `r2`: rate
  - `rex`: rate
  - `s2`: dimensionless
  - `s2axis`: dimensionless
  - `s2f`: dimensionless
  - `s2s`: dimensionless
  - `t1`: time
  - `t1rho`: time
  - `t2`: time
  - `tau_c`: time
  - `tau_e`: time
  - `tau_ex`: time
  - `tau_m`: time
  - `tau_s`: time
8. Oligomer, dimer or association fractions are never `pB`/`population`; set `measured_entity` accordingly.
9. One sample card per construct, mutant, ligand stoichiometry and solvent step; record `uniprot_accession` and `isoform_version` on each sample (use `null` when absent, never placeholders like `x`); a homolog or other construct cannot have `same_as_deposit` = `yes`.
10. Main-article and supplementary text are separate sources: set `document_role` to `main_article` or `supplement_si` for every measurement and qualitative observation; supplementary tables use `evidence_modality` = `si_table`.
11. A value only shown in a figure is recorded with `evidence_modality` `figure_vector` or `figure_raster` and the exact figure/panel locator; never point a locator at a different figure.
12. Record non-numeric dynamics findings (dynamic regions, alternate states, cryptic pockets, no-dynamics controls, suspected artefacts) in `qualitative_observations` with `category`, `evidence_level` (`experimental` vs `author_interpretation` vs `simulation_or_prediction`), `sample_id`, `document_role`, `locator`, and verbatim `quote`.
