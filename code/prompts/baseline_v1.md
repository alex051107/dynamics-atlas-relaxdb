# Task

Find the published literature evidence about the dynamics of the protein described below.

For each relevant paper and experiment, write one row in `rows.csv` (in the current directory) with these columns:

doi, experiment_and_conditions, residues_or_region, alternate_state_structure, timescale, population, quote

Give a DOI for every number. `quote` is a short verbatim sentence from the paper that supports the row. You may download open-access papers into `./sources/`. Do not read files outside the current directory. Also write a short `summary.md`.

Finish with the JSON final message required by the output schema.
